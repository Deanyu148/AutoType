# AutoType（Авто ввод）

Красивый кроссплатформенный инструмент для автоматического ввода текста. Симулирует ввод с клавиатуры в любых приложениях, с режимами реалистичного посимвольного ввода и мгновенной вставки из буфера обмена.

## Возможности

- **Два Режима Ввода** — Посимвольный реалистичный ввод (со случайной вариацией задержки) или мгновенная вставка
- **Поддержка Спецклавиш** — Enter, Tab, Esc, стрелки, F1–F12 через специальные токены
- **Управление Пресетами** — Сохранение, загрузка, импорт/экспорт пресетов (формат YAML), до 50 шт.
- **Глобальные Горячие Клавиши** — F6 старт, F7 стоп, F8 переключение (работает из любого окна)
- **Системный Трей** — Сворачивание в трей с меню быстрого доступа
- **10 Языков Интерфейса** — 中文, English, 日本語, 한국어, Español, Français, Deutsch, Русский, Português, العربية
- **Поверх Всех Окон** — Держать окно поверх остальных
- **Обратный Отсчёт** — Настраиваемая задержка старта 0–10 секунд
- **Регулируемая Скорость** — 1–200 CPS (символов в секунду)
- **Номера Строк** — Редактор с нумерацией строк и подсчётом символов/слов/строк

## Установка

### Запуск из Исходного Кода

```bash
git clone https://github.com/Deanyu148/AutoType.git
cd AutoType
pip install -r requirements.txt
python main.py
```

### Зависимости

- Python 3.9+
- [PySide6](https://pypi.org/project/PySide6/) >= 6.8.2.1 — Qt UI фреймворк
- [pynput](https://pypi.org/project/pynput/) >= 1.7.6 — Симуляция клавиатуры + глобальный слушатель горячих клавиш
- [pyautogui](https://pypi.org/project/pyautogui/) >= 0.9.50 — Мгновенный режим
- [PyYAML](https://pypi.org/project/PyYAML/) >= 6.0 — Импорт/экспорт пресетов

### Сборка EXE (Windows)

```bash
build.bat
```

## Использование

### Основные Операции

1. Введите или вставьте текст в левую панель редактора
2. Настройте скорость, задержку и режим справа
3. Нажмите "Старт" или F6 для начала
4. Установите курсор в целевое поле ввода во время обратного отсчёта (по умолчанию 3 сек)
5. Нажмите F7 для остановки в любой момент

### Специальные Токены Клавиш

Используйте формат `{KEY}` в тексте для вставки специальных клавиш:

| Токен | Клавиша |
|---|---|
| `{ENTER}` | Enter |
| `{TAB}` | Tab |
| `{ESC}` | Escape |
| `{SPACE}` | Пробел |
| `{BACKSPACE}` | Backspace |
| `{DELETE}` | Delete |
| `{UP}` `{DOWN}` `{LEFT}` `{RIGHT}` | Стрелки |
| `{HOME}` `{END}` | Home / End |
| `{PAGEUP}` `{PAGEDOWN}` | Page Up / Down |
| `{F1}` … `{F12}` | Функциональные клавиши |

Пример:
```
пользователь{ENTER}пароль{TAB}{ENTER}Привет, мир! Это автоматически введённый текст.{ENTER}
```

### Режимы Ввода

- **Реалистичный** — Отправляет нажатия клавиш по одному через pynput со случайной вариацией задержки. Имитирует живой ввод.
- **Мгновенный** — Использует буфер обмена + Ctrl+V для вставки всего сразу. Самый быстрый вариант.

### Глобальные Горячие Клавиши

| Клавиша | Действие |
|---|---|
| F6 | Начать ввод |
| F7 | Остановить ввод |
| F8 | Переключить (старт/стоп) |

## Структура Проекта

```
AutoType/
├── main.py                     # Точка входа
├── build.bat                   # Скрипт сборки PyInstaller
├── AutoType.ico                # Иконка приложения
├── requirements.txt            # Зависимости
├── README.md                   # README на китайском
├── docs/                       # README на других языках
└── src/
    ├── core/
    │   ├── autotyper.py        # Движок ввода (поток)
    │   └── key_simulator.py    # Симуляция клавиатуры
    ├── ui/
    │   ├── main_window.py      # Главное окно
    │   ├── editor_panel.py     # Панель редактора текста
    │   ├── settings_panel.py   # Панель настроек
    │   ├── preset_manager.py   # Управление пресетами
    │   ├── widgets.py          # Пользовательские виджеты
    │   └── theme.py            # Определения темы
    └── utils/
        ├── config.py           # Сохранение конфигурации (JSON)
        └── i18n.py             # Интернационализация
```
