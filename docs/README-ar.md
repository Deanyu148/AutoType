# AutoType（أوتو تايب）

أداة كتابة تلقائية جميلة ومتعددة المنصات. تحاكي إدخال لوحة المفاتيح في أي تطبيق، مع وضعين: كتابة واقعية حرفًا بحرف ولصق فوري من الحافظة.

## المميزات

- **وضعا إدخال مزدوجان** — كتابة واقعية حرفًا بحرف (مع تباين عشوائي في التأخير) أو لصق فوري من الحافظة
- **دعم المفاتيح الخاصة** — Enter و Tab و Esc ومفاتيح الأسهم و F1–F12 عبر رموز خاصة
- **إدارة الإعدادات المسبقة** — حفظ وتحميل واستيراد/تصدير الإعدادات المسبقة (بصيغة YAML)، حتى 50 إعدادًا
- **اختصارات عامة** — F6 للبدء و F7 للإيقاف و F8 للتبديل (يعمل من أي نافذة)
- **شريط النظام** — تصغير إلى شريط النظام مع قائمة وصول سريع
- **10 لغات للواجهة** — 中文 و English و 日本語 و 한국어 و Español و Français و Deutsch و Русский و Português و العربية
- **دائمًا في المقدمة** — إبقاء النافذة فوق النوافذ الأخرى
- **عد تنازلي للبدء** — تأخير بدء قابل للتكوين من 0–10 ثوانٍ
- **سرعة قابلة للتعديل** — 1–200 حرف/ثانية
- **أرقام الأسطر** — محرر مع أرقام الأسطر وعداد الأحرف/الكلمات/الأسطر

## التثبيت

### التشغيل من الكود المصدري

```bash
git clone https://github.com/Deanyu148/AutoType.git
cd AutoType
pip install -r requirements.txt
python main.py
```

### التبعيات

- Python 3.9+
- [PySide6](https://pypi.org/project/PySide6/) >= 6.8.2.1 — إطار عمل Qt للواجهة
- [pynput](https://pypi.org/project/pynput/) >= 1.7.6 — محاكاة لوحة المفاتيح + مستمع الاختصارات العامة
- [pyautogui](https://pypi.org/project/pyautogui/) >= 0.9.50 — الوضع الفوري
- [PyYAML](https://pypi.org/project/PyYAML/) >= 6.0 — استيراد/تصدير الإعدادات المسبقة

### بناء EXE (Windows)

```bash
build.bat
```

## الاستخدام

### التشغيل الأساسي

1. اكتب أو الصق النص في لوحة المحرر اليسرى
2. اضبط السرعة والتأخير والوضع في اللوحة اليمنى
3. انقر على "بدء" أو اضغط F6 للبدء
4. ضع المؤشر في حقل الإدخال المستهدف أثناء العد التنازلي (3 ثوانٍ افتراضيًا)
5. اضغط F7 للإيقاف في أي وقت

### رموز المفاتيح الخاصة

استخدم صيغة `{KEY}` في النص لإدراج مفاتيح خاصة:

| الرمز | المفتاح |
|---|---|
| `{ENTER}` | Enter |
| `{TAB}` | Tab |
| `{ESC}` | Escape |
| `{SPACE}` | مسافة |
| `{BACKSPACE}` | Backspace |
| `{DELETE}` | Delete |
| `{UP}` `{DOWN}` `{LEFT}` `{RIGHT}` | مفاتيح الأسهم |
| `{HOME}` `{END}` | Home / End |
| `{PAGEUP}` `{PAGEDOWN}` | Page Up / Down |
| `{F1}` … `{F12}` | مفاتيح الوظائف |

مثال:
```
اسم المستخدم{ENTER}كلمة المرور{TAB}{ENTER}مرحبًا بالعالم، هذا نص مكتوب تلقائيًا.{ENTER}
```

### أوضاع الإدخال

- **واقعي** — يرسل ضغطات المفاتيح واحدة تلو الأخرى عبر pynput مع تباين عشوائي في التأخير. يحاكي الكتابة البشرية.
- **فوري** — يستخدم الحافظة + Ctrl+V للصق كل النص دفعة واحدة. الخيار الأسرع.

### الاختصارات العامة

| المفتاح | الإجراء |
|---|---|
| F6 | بدء الكتابة |
| F7 | إيقاف الكتابة |
| F8 | تبديل (بدء/إيقاف) |
